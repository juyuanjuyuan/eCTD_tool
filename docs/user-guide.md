# eCTD 在线文档撰写工具 — 用户操作手册

## 1. 系统概述

eCTD 在线文档撰写工具是面向药企注册申报团队的 Web 端平台，支持按 CTD 五模块结构在线编辑申报资料，自动生成符合 NMPA《eCTD 技术规范 V1.1》要求的提交包。

### 1.1 核心功能

- **CTD 五模块在线编辑** — 按模块一至模块五结构撰写/编辑申报文档
- **eCTD 提交包生成** — 自动生成 index.xml、cn-regional.xml、index-md5.txt
- **文档导出** — 支持 Word (.docx) 和 PDF 格式导出
- **eCTD 合规验证** — 内置 80+ 条验证规则，对齐 CDE 验证标准 V1.1
- **协作审批** — 多人编辑、编辑锁、审批流程、评论系统
- **文件管理** — 文件上传、命名规范化、PDF 合规检查

### 1.2 用户角色

| 角色 | 权限 |
|------|------|
| ADMIN | 系统管理、用户管理 |
| MANAGER | 项目管理、审批通过/驳回、强制解锁 |
| EDITOR | 文档编辑、文件上传、提交审批 |

## 2. 快速开始

### 2.1 登录系统

1. 在浏览器访问系统地址（默认 http://localhost）
2. 输入邮箱和密码，点击"登录"
3. 首次使用请先注册账户

### 2.2 创建项目

1. 在项目列表页点击"新建项目"
2. 输入项目名称和描述
3. 项目创建者自动成为 OWNER

### 2.3 创建申请

1. 进入项目详情页
2. 点击"新建申请"
3. 选择：
   - **申请类型**: 临床试验(cnapt1)/新药(cnapt2)/仿制药(cnapt3)/原料药(cnapt4)
   - **产品类型**: 化学药品(cnprt1)/生物制品(cnprt2)
   - **原始编号**: 10 位（年份 4 位 + 流水号 6 位）
4. 系统自动生成申请编号（前缀 x/y/l/s + 9 位数字）

### 2.4 创建注册行为

1. 在申请详情页点击"新建注册行为"
2. 选择注册行为类型（首次申请 cnrat1、补充申请 cnrat2 等）
3. 系统自动验证申请类型与注册行为类型的合法组合

### 2.5 创建序列

1. 在注册行为下点击"新建序列"
2. 填写序列类型、描述、联系人信息
3. 首个序列自动编号 0000，后续依次递增

## 3. eCTD 提交包制作

### 3.1 初始化 CTD 目录

1. 进入序列详情页
2. 点击"初始化 CTD 目录"
3. 系统自动创建 229 个 CTD 节点（5 模块/43 章节/180 叶节点/1 扩展点）
4. 查看"必填章节清单"了解当前申请类型的必填要求

### 3.2 编辑文档

1. 点击"进入编辑器"打开三栏编辑界面
2. **左栏**: CTD 目录树 — 点击节点选择要编辑的章节
3. **中栏**: 富文本编辑器 — 支持标题、表格、列表、图片等
4. **右栏**: 属性面板 — 查看/修改节点属性、文件管理、审批
5. 编辑器支持 3 秒自动保存，切换节点时自动保存当前内容

### 3.3 上传文件

1. 在属性面板的"文件"标签页
2. 拖拽或点击上传文件
3. 支持格式: PDF、XML、XPT、TXT、XSL
4. 系统自动执行：
   - 文件名规范化（大写转小写、特殊字符替换）
   - 路径长度验证（≤180 字符）
   - PDF 合规检查（版本/加密/书签等 8 项检查）
   - MD5 校验值计算

### 3.4 文件复用

同一申请内，可引用前序序列的文件避免重复上传：
1. 在文件管理中点击"引用文件"
2. 从前序序列的文件列表中选择
3. 引用文件不占用新存储空间

### 3.5 运行验证

1. 点击编辑器顶栏"运行 eCTD 验证"按钮
2. 系统执行 80+ 条验证规则，包括：
   - **1.x 基础识别**: 文件数/大小统计
   - **2.x 文件规范**: 文件大小(≤500MB，XPT≤4GB)/命名(a-z0-9-_)/路径长度/扩展名
   - **3.x ICH 骨架**: 操作类型/首次提交全 NEW/modified-file/路径分隔符
   - **4.x 区域信息**: 申请编号格式/受控词汇/原始编号/序列号/联系人
   - **4.3.x 完整性**: 必填/禁止章节规则
   - **5.x STF**: 模块四/五的研究标签文件必填
   - **6.x PDF**: 版本 1.4-1.7/加密/JS/书签/外部链接/多媒体/附件
3. 验证结果分为: 错误(红色，阻止导出)、警告(黄色)、提示(蓝色)

### 3.6 导出 eCTD 包

验证通过后：
1. 进入序列详情的"eCTD 导出"标签页
2. 预览文件结构树
3. 点击"导出 ZIP 包"
4. 生成的包包含：
   - `index.xml` — ICH 骨架文件（模块二至五）
   - `cn-regional.xml` — 区域骨架文件（模块一 + 信封元素）
   - `index-md5.txt` — 文件校验
   - `m1/` ~ `m5/` — 五个模块文件夹
   - `util/` — DTD/Schema/XSL/valid-values 配套文件

## 4. 各申请类型操作指南

### 4.1 临床试验申请 (cnapt1)

- 申请编号前缀: `x`
- 可用注册行为: cnrat1(首次)、cnrat2(补充)、cnrat4(通知)
- 必填章节: 按 4.3.1 规则，通常包含模块一行政文件 + 模块二概述

### 4.2 新药申请 (cnapt2)

- 申请编号前缀: `x`
- 可用注册行为: cnrat1(首次)、cnrat2(补充)、cnrat3(再注册)等
- 必填章节最多，涵盖全部五个模块

### 4.3 仿制药申请 (cnapt3)

- 申请编号前缀: `y`
- 可用注册行为: cnrat1(首次)、cnrat8(再注册)等
- 模块四/五要求相对较少

### 4.4 原料药申请 (cnapt4)

- 申请编号前缀: `s`
- 重点在模块三(质量)的原料药部分 (3.2.S)
- 不需要模块四/五的临床/非临床数据

### 4.5 生物制品特殊要求

- 产品类型选择 `cnprt2`(生物制品)
- 可使用扩展节点 3.2.R (3.2.R.1 ~ 3.2.R.6)
- 在 CTD 树中右键点击 3.2.R 添加扩展节点

## 5. 审批流程

### 5.1 提交审批

1. 完成章节编辑后，在属性面板点击"提交审批"
2. 节点状态变为 SUBMITTED（蓝色时钟图标）

### 5.2 审批操作（MANAGER 角色）

1. 在属性面板"审批"标签页
2. 查看节点审批状态和历史
3. 点击"通过"或"驳回"
4. 驳回时需填写驳回理由

### 5.3 审批状态流转

```
DRAFT → SUBMITTED → APPROVED (通过)
                  → REJECTED (驳回) → SUBMITTED (重新提交) → ...
```

### 5.4 解锁审批

MANAGER 可将已审批节点重置为 DRAFT 状态，允许重新编辑。

## 6. 常见验证错误及修复方法

| 错误代码 | 描述 | 修复方法 |
|----------|------|---------|
| 2.2 | 文件大小超过 500MB（XPT 4GB） | 压缩 PDF 文件或拆分为多个文件 |
| 2.4 | 文件扩展名不合规 | 仅使用 pdf/xml/xpt/txt/xsl 格式 |
| 2.5 | 文件名包含非法字符 | 仅使用小写字母 a-z、数字 0-9、连字符 -、下划线 _ |
| 2.5 | 路径超过 230 字符 | 缩短文件名 |
| 3.4 | 非 DELETE 操作的叶元素无文件 | 上传对应文件 |
| 3.6 | 首次提交使用了非 NEW 操作 | 序列 0000 的所有叶元素必须为 NEW |
| 3.8 | REPLACE/DELETE 操作缺少前序引用 | 确保前序序列中存在对应节点 |
| 3.9 | 文件路径包含反斜杠 | 系统自动修正，如仍出现请联系管理员 |
| 3.16 | DELETE 操作包含文件附件 | 删除操作不应有文件，移除附件 |
| 4.2.2 | 申请编号格式错误 | 格式: 字母前缀 + 9 位数字（如 x202600001） |
| 4.2.11 | 缺少联系人信息 | 在序列设置中填写联系人姓名/电话/邮箱 |
| 5.1 | 模块四/五节点缺少 STF | 为需要 STF 的节点创建研究标签文件 |
| 6.1 | PDF > 5 页无书签 | 使用 Adobe Acrobat 为 PDF 添加书签 |
| 6.18 | PDF 版本不在 1.4-1.7 范围 | 转换 PDF 为 1.4-1.7 版本或 PDF/A |
| 6.19 | PDF 文件已加密 | 移除 PDF 加密保护 |
| 6.20 | PDF 包含 JavaScript | 移除 PDF 中的 JavaScript 代码 |
| 6.21 | PDF 包含外部链接 | 系统自动剥除，或手动移除 http/mailto 链接 |
| 6.22 | PDF 包含多媒体内容 | 移除视频/音频/3D 内容 |
| 6.24 | PDF 包含附件 | 移除 PDF 中嵌入的附件 |

## 7. 电子签章操作指南

### 7.1 需要签章的章节

以下 6 类章节必须添加电子签章：
- cn-1-0 说明函
- cn-1-2 申请表
- cn-1-3-8
- cn-1-10
- cn-1-11
- cn-1-12

### 7.2 签章流程

1. 上传的 PDF 文件应包含合法的电子签章
2. 系统验证签章章节的文件是否已签署
3. 签章后的 PDF 不可再修改内容
